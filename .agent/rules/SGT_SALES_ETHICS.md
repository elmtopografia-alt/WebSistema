# SGT SALES ENGINE: PROTOCOLO DE ACESSO (O "ENTENDIMENTO")

> "Não invadimos. Entramos onde a porta está aberta."

Este documento define as regras irrevogáveis (Hard Rules) para todos os agentes e scripts de prospecção do SGT.

## 1. O Princípio da Permissão Passiva (The Open Door)

O sistema SÓ está autorizado a capturar dados ou interagir se o alvo oferecer um canal público e inequívoco de entrada.

### ✅ Acesso Permitido (Autorização Explícita)

Consideramos "Convite para Entrar":

- **Formulários de Contato:** Se existe um `<form>` de "Fale Conosco", temos permissão para preencher.
- **Links `mailto:`:** Se o e-mail está visível (ex: `contato@empresa.com`), temos permissão para enviar.
- **Links WhatsApp (`wa.me`):** Se o link de chat direto existe, temos permissão para chamar.
- **Redes Sociais Públicas:** Se a empresa posta no LinkedIn/Instagram, temos permissão para interagir no post.

### 🚫 Acesso Negado (Invasão)

É estritamente PROIBIDO:

- **Tentar adivinhar e-mails:** (ex: tentar `joao@...`, `maria@...` sem ver o e-mail lá).
- **Explorar falhas:** Tentar URLs administrativas (`/admin`, `/login`).
- **Ignorar `robots.txt`:** Se o site diz "User-agent: * Disallow: /", nós saímos.
- **Dados Pessoais Sensíveis:** Não capturamos CPF, Endereço Residencial ou dados não-comerciais.

## 2. A Mecânica da Abordagem

- **Identificação:** O robô deve sempre se identificar (User-Agent) como "SGT Prospector Bot" para que o dono do site saiba quem somos.
- **Cadência:** Respeitar o tempo humano. Não enviar 50 forms em 1 minuto.

## 3. Objetivo Final

**Encher o Copo** com relacionamentos permitidos. Criar uma base de dados onde 100% dos contatos estão esperando ou aceitando comercialmente uma abordagem.
